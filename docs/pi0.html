2024 · PHYSICAL INTELLIGENCE

π0 精读

1. 问题：语义与高频控制之间的鸿沟

2024 年的 VLA（RT-2、OpenVLA 一系）把动作离散成 token 自回归生成——这在语义层面优雅，但在高频灵巧操作上撞墙。论文原文的判断是：高频动作块与高度灵巧任务“对先前的自回归 VLA 构成主要挑战”——离散化有精度损失、逐 token 串行解码慢、自回归逐点生成难以表达连续轨迹的多模态分布。π0 的答案：动作连续生成 + flow matching，成为第一个用 flow matching 产出高频动作块的 VLA。

2. 架构精读

2.1 双权重块 + 同一序列（Transfusion 式）

π0 = PaliGemma 3B（SigLIP 视觉编码器 + Gemma 语言模型，互联网级预训练）+ 动作专家约 300M（从头初始化），合计 3.3B。关键在交互方式：图像/语言 token 走 VLM 权重，机器人状态与带噪动作 token 走动作专家权重，但所有 token 在同一序列里做联合 attention——论文明确说这是“两个混合元素的 mixture of experts”式设计，灵感来自 Transfusion（单 Transformer 多目标训练）。动作专家不是接在 VLM 后面的另一个模型，而是同一次前向里并行工作的独立权重块。

2.2 Flow matching 动作块（H=50）与 β 采样

动作块记 $\mathbf{A}^\tau_t = [\mathbf{a}^\tau_t, ..., \mathbf{a}^\tau_{t+H-1}]$，动作地平线 H=50（50Hz 口径约 1 秒）。训练时把带噪动作 token 与时间步 $\tau$ 塞进序列，只对 H 个动作位置计算流匹配损失；$\tau$ 从一个偏移的 beta 分布采样，刻意强调更低（更噪）的时间步，并在截止值 s=0.999 以上完全不采样——最难的“从纯噪声出发”那一段被过采样。推理从 $A^0_t \sim N(0, I)$ 出发沿学到的向量场从 $\tau=0$ 积分到 $\tau=1$（论文附录 A-D 给出各阶段推理耗时拆分）。

3. 训练与数据

预训练混合 = 自有灵巧操作数据（7 种机器人构型、68 个任务）+ 完整 OXE 数据集（22 种机器人），总量超过 10,000 小时。构型清单本身有信息量：双臂 UR5e（3 相机、14 维配置/动作空间）、Franka（2 相机、8 维）、双臂 ARX/AgileX（3 相机、14 维）等——不同本体靠统一的序列接口对齐，而不是各自微调。预训练后按任务微调，覆盖叠衣服、收桌子、装盒子等。

4. 结果与消融

三组对照值得记住：①π0-small：470M 的无 VLM 初始化消融版——即使它也超过了 OpenVLA 和 Octo，但远不如完整 π0，证明“互联网预训练主干”是性能来源；②与 OpenVLA / Octo 的“对齐训练量”（160k steps）对比，π0 全面占优，论文点破原因：“OpenVLA 的自回归离散化架构不支持动作块”；③OpenVLA 只在 UR5e 数据上训练时表现更好，但仍远低于 π0。2025 年开源 openpi（JAX/PyTorch 双实现，含 LoRA 微调配方），成为社区最重要的 VLA 基座。

5. 研究者注记

①动作频率 ≠ 推理频率：50Hz 是动作块内动作点的时间参数化，模型重规划频率低得多——块间衔接（RTC/ensembling）是独立的工程问题。②“VLM + 小动作专家 + 分块注意力”是一个可复用骨架：SmolVLA 换成 SmolVLM2 照用，π0.5/π0.6/π0.7 沿用。③flow matching vs 扩散的取舍（直线路径、步数可调、确定性采样）在 DP 页的去噪动画语境下理解最直观：π0 本质上把“扩散的随机游走”换成了“直线流”。④β 采样强调“更噪的时间步”是个可迁移的训练技巧：最难的去噪段最值得学。
