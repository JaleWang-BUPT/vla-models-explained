π0

π0 要回答的问题是：互联网级的语义知识，能不能直接接到 50 Hz 的灵巧操作上？它的架构成了后来大部分 VLA（含 SmolVLA）的模板：一个预训练 VLM 主干负责“看懂”，一个小得多的动作专家负责“动手”。

方法

动作专家用 flow matching 训练：把噪声与真值动作沿直线路径插值，网络回归速度场，推理时从噪声沿直线 Euler 积分数步得到动作块。相比扩散的多步随机去噪，flow matching 步数可调、路径直、确定性采样，天然适配高频控制——π0 用它做到了 50 Hz 的动作输出（叠衣服级别的灵巧任务）。

数据与结果

预训练混合了自有灵巧操作数据与开源机器人数据，总量超过 10,000 小时；微调后覆盖叠衣服、收桌子、装盒子等高难度灵巧任务。2025 年以 openpi 项目开源，是社区目前最重要的 VLA 基座之一。

研究者注记

①“大 VLM + 小动作专家”的配比是刻意的：语义知识在主干，动作专家只学“怎么动”，两者用分块注意力在同一个序列里交互——不是级联两个模型。②π0 仍是模仿学习范式，数据外的错误会复合；它的后续（π0.5 泛化、π*0.6 可靠性、π0.7 条件化）各自补一块短板。③动作频率 ≠ 推理频率：50 Hz 是动作点的时间参数化，模型重规划频率远低于此。

参考：Black et al., π0: A Vision-Language-Action Flow Model for General Robot Control（arXiv:2410.24164 · 官方博客 · openpi）
