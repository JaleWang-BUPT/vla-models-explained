π0.5 精读

1. 问题：场景级泛化

π0 时代（含同期所有 VLA）的评测环境都与训练环境高度相似；商业机器人因此只敢进工厂和仓库。π0.5 把目标定为在从未见过的家庭里完成长程任务——收拾厨房（关柜门、把物品放进水槽）、收拾卧室（捡起地上所有衣服）——并且明确声明：目标不是新技能或更高灵巧度，而是泛化本身。训练演示仍然“通常短于一分钟、成功率不高”，泛化不是靠完美数据堆出来的。

2. 方法精读：共训 + 混合多模态样本 + 分层微调

π0.5 采用简单而清晰的分层架构：先在异构混合任务上预训练，再针对移动操作微调——微调数据同时含底层动作样本与高层“语义”动作（预测“pick up…”这类子任务标签）。推理时模型先推断高层子任务，再以子任务为条件预测连续动作（动作解码仍是 flow matching）。核心观察：VLA 继承自 VLM，训练样本可以是“图像、文本、检测框、动作”的任意组合——于是 π0.5 把共训做到了 VLM 数据之外：

此前工作已证明“混入 VLM 训练数据”能改善对新物体/新背景的泛化；π0.5 更进一步，设计了混合多模态样本（hybrid multimodal）：一条样本同时含图像观测、语言命令、物体检测、语义子任务预测与底层动作。官方博客把提示/标注形态画成四类，正对应本站下载的四张官方图：

2.1 实现细节里值得抄的三处

  • 所有动作数据按数据集各自的 1%/99% 分位归一化到 $[-1,1]$；动作维度取全体数据集的最大维，低维本体 padding——跨本体数据的统一接口做法。
  • 语义命令以特定标记（如 ' > '）追加到文本提示里，让“子任务预测”与“语言跟随”在同一模板下共存。
  • 评测用部分得分（partial credit）评分细则（附录 A-B 的任务评分 rubric）：把一半盘子放进水槽记约 50%——长程任务的成功率统计必须有这类协议，否则数字没有意义。

3. 结果与消融

评测在多个训练时完全没见过的家庭进行。三个系统性结论：①泛化随训练地点数稳步上升（语言跟随实验：随训练场景增加，对已见/未见物体类别的成功率都持续提高——场景多样性是可积累的资产）；②共训配方消融（V-C 节）逐一验证语义预测、web 数据等成分的边际贡献；③高层推理消融（V-E 节）：去掉子任务预测，长程任务的阶段衔接明显变差。任务从“把盘子放进水槽”到“用海绵擦溅洒”，失败常见但展现出类人的灵活应变。

4. 研究者注记

①π0.5 把“数据工程”变成“接口工程”：难点不在收集更多数据，而在让异质数据共享同一个序列模板。②子任务先行的两阶段推理是分层策略的最小实现——不引入额外模型，只是让 VLM 部分先说一句话。③它仍然只解决“见过类似技能在新场景执行”；π0.7 的组合泛化（没见过的电器）是下一层。
