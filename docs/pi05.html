π0.5 精读

1. 问题：场景级泛化

π0 时代（含同期所有 VLA）的评测环境都与训练环境高度相似；商业机器人因此只敢进工厂和仓库。π0.5 把目标定为在从未见过的家庭里完成长程任务——收拾厨房（关柜门、把物品放进水槽）、收拾卧室（捡起地上所有衣服）——并且明确声明：目标不是新技能或更高灵巧度，而是泛化本身。

2. 方法精读：共训 + 混合多模态样本

π0.5 的核心观察：VLA 继承自 VLM，而 VLM 的训练样本本来就是“图像、文本、框、动作的任意组合”。于是 π0.5 的训练样本是混合多模态（hybrid multimodal）的：一条样本可以同时含图像观测、语言命令、物体检测、语义子任务预测与底层动作——不同来源的数据不再需要严格的同构对齐，因为它们共享同一个序列接口。共训配方对应四类形态（官方图）：

2.1 两阶段推理

推理时模型先推断高层子任务（语义命令），再以子任务为条件预测连续动作——动作解码仍是 flow matching（继承 π0）。这个分层让长程任务（铺床 = 拉平枕套 → 铺平 → 摆正）有了显式的阶段结构，也是后来 π0.7 “语言教练”能力的雏形。

2.2 实现细节里值得抄的三处

  • 所有动作数据按数据集各自的 1%/99% 分位归一化到 $[-1,1]$；动作维度取全体数据集的最大维，低维本体 padding——跨本体数据的统一接口做法。
  • 语义命令以特定标记（如 ' > '）追加到文本提示里，让“子任务预测”与“语言跟随”在同一模板下共存。
  • 评测用部分得分（partial credit）评分细则：把一半盘子放进水槽记约 50%——长程任务的成功率统计必须有这类协议，否则数字没有意义。

3. 结果与消融

评测在多个训练时完全没见过的家庭进行（收厨房、收卧室等长程任务），π0.5 能持续完成任务、展现类人的应变。三个系统性结论：①泛化随训练地点数稳步上升（语言跟随实验里，随训练场景增加，对已见/未见物体类别的成功率都持续提高）——场景多样性是可积累的资产；②共训配方消融（V-C 节）逐一验证了语义预测、web 数据等成分的边际贡献；③高层推理消融（V-E 节）：去掉子任务预测，长程任务的阶段衔接明显变差。

4. 研究者注记

①π0.5 把“数据工程”变成“接口工程”：难点不在收集更多数据，而在让异质数据共享同一个序列模板。②子任务先行的两阶段推理是分层策略的最小实现——不引入额外模型，只是让 VLM 部分先说一句话。③它仍然只解决“见过类似技能在新场景执行”；π0.7 的组合泛化（没见过的电器）是下一层。
