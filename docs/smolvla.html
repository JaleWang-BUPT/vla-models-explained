SmolVLA

当 PI 把模型越做越大时，Hugging Face 反向操作：450M 参数的 VLA，消费级 GPU 可训、浏览器/MacBook 可跑，训练数据来自 LeRobot 社区数据集。它证明了一件事：如果架构和推理调度够聪明，VLA 不必是奢侈品。

效率三件套

  1. 视觉 token 削减：砍掉图像 token 数量，让小模型的重心放在动作上。
  2. 层跳过（layer skipping）：推理时跳过 VLM 的部分上层——小任务上深层语义冗余，换来明显加速。
  3. 交错注意力：动作专家里 cross-attention 与 self-attention 交错，让动作 token 高效利用 VLM 特征。

结果与研究者注记

在 LIBERO / Meta-World 仿真与 SO-100/SO-101 真机任务上验证，跨本体（单臂、双臂、移动底盘）训练后相互增益；配套 LeRobot 集成使其成为社区复现门槛最低的 VLA。

①异步推理是“系统工程换性能”的典范——模型没变，把推理延迟藏进执行时间里（对比本站 π0 页的 flow matching 动画：块与块之间的空闲就是它吃掉的）。②它和 π0 共享 flow matching 动作头，说明该范式已足够成熟、可以下沉到 450M。③社区数据的噪声与相机多样性是它泛化的本钱——也是 π0.7 “元数据消毒”思路的潜在受益者。

参考：Shukor et al., SmolVLA: A Vision-Language-Action Model for Affordable and Efficient Robotics（arXiv:2506.01844 · HF 博客 · LeRobot）
