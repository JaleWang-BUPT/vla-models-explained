π*0.6 与 RECAP 精读

1. 问题：从“偶尔成功”到“持续可靠”的鸿沟

模仿学习的失败模式有清晰的机制：误差复合。VLA 在真机上犯一个小错（比如以错误角度抓住咖啡机手柄），环境随即进入训练分布外的状态，下一步更容易犯错——而真正的失败原因可能发生在几步之前，监督学习只在“当时正确”的轨迹上训练，永远不会修正这种早期偏差。所以 VLA“偶尔成功容易，持续可靠很难”。π*0.6（π0.6 基座 + RECAP 后训练）给出了一套可复制的解法。

2. RECAP 精读（RL with Experience & Corrections via Advantage-conditioned Policies）

2.1 价值函数：给“坏经验”打标签

自主经验数据的问题是没有真值标签——照抄自己的失败毫无意义。RECAP 训一个价值函数：预测“当前处境相对其他处境有多好”（博客用棋局类比：预测从当前盘面赢棋的概率）。有了它，就能对一段自主 rollout 做回溯归因——哪怕失败发生在最后一步，也能把“以错误角度抓 Portafilter”标记为错误。信用分配问题（早期错误、晚期暴露）由此被价值函数的回溯性质解决。

2.2 优势条件化：策略优于训练数据

“价值的相对变化”在 RL 里叫优势（advantage）。RECAP 的独特之处是把优势作为条件输入策略（advantage-conditioned），而不只是当加权系数：执行时直接要求 VLA “执行高优势动作”。这样学出的策略可以优于产生它数据的平均质量——数据里好坏混合，条件化让模型学会在推理时选择好的一端。

2.3 三个数据来源，两种“坏数据”的好用法

RECAP 训练数据 = 演示（遥操作打底）+ 纠正（专家在策略跑偏时接手拉回——含“如何修复错误/做得更好”的信息）+ 自主经验（价值函数打标签）。博客强调的两个技巧：纠正数据教会“从错误恢复”，自主数据教会“不犯第一次错”——两种“坏经验”都被转化成训练信号。

3. 结果

  • 最难的几个任务吞吐量 翻倍以上，失败率至少减半；
  • 咖啡制作从 5:30am 连续跑到 11:30pm（全天商用时段）；
  • 新家叠 50 件未见衣物数小时不中断；真实工厂里装配并贴标 59 个巧克力包装盒；
  • 三段未剪辑长视频全部公开（官方博客“Real-time versions”链接）。

4. 研究者注记

①RECAP 的可复用模板：价值函数 = 自主经验的标注器；优势条件化 = 让策略“高于数据分布”的旋钮；纠正数据 = 恢复行为的监督来源。三件事各自独立，可单独移植到任何 VLA 后训练管线。②注意数据闭环：RECAP 产生的自主经验 + 价值标注，就是 π0.7 页面里“带策略元数据并入通用训练”的那批数据——π*0.6 是特化模型，也是 π0.7 的数据工厂。③复现级细节官方未完全公开（价值模型结构、优势离散化方式），开源社区的对标实现可关注 openpi 的 RL 分支进展。
