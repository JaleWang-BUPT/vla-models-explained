π0.7 精读

1. 问题：组合泛化为什么在 VLA 里迟迟没出现

LLM 的标志性能力是重组：会英译法 + 会输出 JSON，就能输出 JSON 格式的翻译。VLA 能理解丰富的语义概念，却一直做不到“把学过的技能组合起来解决新任务”——比如用一件训练时没见过的厨房电器。此前哪怕训练中见过的技能，想用好也都要按任务微调，“通用模型开箱即专家”停留在愿景。π0.7（2026-04）展示的正是这个愿景的第一批实证。

2. 方法精读：多样化上下文条件

核心论断：naive 地混合多源数据不会带来好的泛化；泛化的关键是把“怎么做的差异”写进提示。π0.7 的提示除语言指令外，还包括：

  • 子目标图像（subgoal images）：定义“当前子步骤结束时物体该被摆成什么样”的精确空间布局；
  • 元数据（metadata）：episode 的期望时长（做得多快）、质量标注（好/差）——次优的自主评测数据标注上“低质量/低速”后就能入库而不会教坏模型；
  • 策略描述：文本化的执行策略。

测试时模型接受标准语言指令，但也接受期望策略信息、甚至由轻量世界模型合成的视觉子目标——世界模型在这里的角色是“提示生成器”，为没有真值子目标的任务提供视觉条件。

3. 数据侧：把 π*0.6 的经验变成通用训练数据

训练数据横跨多机器人、人类数据、以及各策略跑出的自主 episode。关键的缝合技巧：把 π*0.6 经 RECAP 产生的自主经验带策略元数据并入 π0.7 训练——同一批“特化模型的经验”就这样变成“通用模型的通识”。

4. 三个涌现能力与数字

4.1 开箱即专家

在叠衣（T-Shirts & Shorts / Diverse-Hardest Item 两档难度）、咖啡制作、装盒任务组上，单个 π0.7 的吞吐（按专家特化模型归一化）达到持平或更高，成功率相当——即“通用模型 ≥ 特化模型”，这是“开箱即专家”主张的直接证据。

4.2 语言教练（language coaching）

面对没见过的厨房电器（空气炸锅），机器人收到的是逐步语言命令——和指导第一次用电器的人一样。之后把高层策略微调成“自动生成语言子任务”的版本，无需任何额外遥操作，任务的全自主执行显著改善——机器人实际上“从语言教练那里学会了任务”。页面可视化里还能看到世界模型合成的子目标图逐步变化。

4.3 零样本跨本体

训练集中最欠 represented 的本体之一是双臂 UR5e 系统（两台 UR5e 工业臂 + Robotiq 平行夹爪）——臂重大惯量大、夹爪精度低、极难遥操作。π0.7 在这台机器人上零样本叠衣（无任何该本体的叠衣数据），成功率与“首次在这台机器人上做该任务的人类专家遥操作者”持平。

5. 研究者注记

①π0.7 的深层主张是数据护城河的重新定义：泛化不靠“更多同质数据”，靠“条件化消化异质数据”——低质量数据从负资产变成（带标注的）资产，数据工程的重心从“采好数据”移到“把数据之间的差异写清楚”。②世界模型路线之争在这里被降维：世界模型不必是“另一个大模型路线”，它可以是 VLA 的子目标生成器——一条轻量的融合路径。③开放问题：子目标合成的保真度成为新上界；元数据标注从哪来（人工/自动评测）是数据管线的下一个瓶颈；RECAP 经验的“策略元数据”具体形式官方未完全公开。
