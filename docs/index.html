VLA METHODS, VISUALLY

从 Diffusion Policy 到 π0.7：VLA 方法精读图解

一份面向研究者的中文精读笔记，沿“动作怎么生成、数据怎么用、泛化从哪来、可靠性怎么建”四条线拆解六个代表性模型：Diffusion Policy（2023）→ π0（2024）→ π0.5（2025）→ SmolVLA（2025）→ π*0.6（2025）→ π0.7（2026）。每页固定结构：问题 → 方法精读（含公式与架构细节）→ 训练与实现 → 结果与消融 → 研究者注记。所有论文图与官方动画逐条署名；机制动画（✳）为本站自制的 SVG/SMIL，零 JS、可自由复用。

这六个模型恰好构成一条完整的因果链：DP 立住“动作=生成模型”→ π0 把它接进 VLM 与 50Hz 控制 → π0.5 解决场景泛化 → SmolVLA 证明范式可小型化 → π*0.6 用 RL 补可靠性 → π0.7 把前面所有数据源用“条件化”统一起来。读的时候建议对照每页的“研究者注记”。

时间线

  • 2023 · RSS　Diffusion Policy：把动作生成变成去噪。多模态动作分布的表达第一次在真机上立住，15 个任务平均成功率 60.7%（此前 SOTA 44.6%）。
  • 2024 · π0　Physical Intelligence：PaliGemma 3B + 300M flow matching 动作专家，7 构型 68 任务 + OXE 全集预训练，把语义先验接到 50Hz 灵巧操作。
  • 2025 · π0.5　：异构共训（网络多模态 + 多本体 + 语义标注），推理先出子任务再出动作，泛化到训练时没见过的家庭。
  • 2025 · SmolVLA　Hugging Face：450M、481 个社区数据集 22.9K episodes 预训练，消费级 GPU 可训；异步推理响应快 30%、吞吐 2×。
  • 2025 · π*0.6　：RECAP 后训练（演示 + 纠正 + 自主经验 + 优势条件化），最难任务吞吐翻倍、失败率减半，咖啡做到全天连续。
  • 2026 · π0.7　：多样化上下文条件——提示里给“怎么做”（子目标图/元数据/策略），同一模型开箱达到专家特化水平，零样本跨本体叠衬衫。

四条研究主线

  1. 动作表示：离散 token（RT-2/OpenVLA 一系）→ 回归 → CVAE（ACT）→ 扩散（Diffusion Policy）→ flow matching（π0 及之后全部）。判据有三：分布表达力（多模态）、推理步数可调（延迟换精度）、对高频连续控制的适配（50Hz 级动作点）。
  2. 数据复用：单任务演示 → 异构共训（π0.5：网络数据 + 语义标注）→ 社区数据（SmolVLA：10.6M 帧）→ 自主经验回收（π*0.6：价值函数当标签）→ 低质量数据经元数据“消毒”后入库（π0.7）。
  3. 泛化来源：π0.5 靠“见多”（地点规模曲线持续上升）→ π0.7 靠“条件化”（把数据差异显式写进提示），组合泛化开始像 LLM。
  4. 可靠性：模仿学习的小错误会复合（π*0.6 页的 Portafilter 案例）→ 价值函数给经验打标签 → 优势条件化让策略“优于训练数据”。
